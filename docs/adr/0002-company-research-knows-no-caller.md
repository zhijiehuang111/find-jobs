# 公司調查不認識呼叫端

公司調查對外只有一個 function：輸入公司全名、調查項目和已知資料，輸出調查報告。它不 import find-jobs 的任何東西，不碰資料庫，也不認識 104。104 的公司簡介由 find-jobs 先抓好，當成已知資料傳進去；報告要存在哪裡、「調查中」的狀態怎麼記，也都由 find-jobs 自己處理。

這樣做的目的是，之後可以把公司調查拆成獨立的服務，給其他情境用（例如分析投資標的）。

## Considered Options

- **把「抓 104 簡介」做成 agent 的工具**：沒有選。find-jobs 每次都需要這份簡介，一定要做的事不該交給 LLM 決定要不要做（舊版的 `fetch_page` 工具就一次都沒被呼叫過）。而且其他呼叫端用不到這個工具，多一個工具只會讓 LLM 多一個可能選錯的選項。
- **模組自己管儲存**：沒有選。目前只有一個呼叫端，它本來就有 Postgres。等真的拆成獨立服務，再決定要不要有自己的儲存。
